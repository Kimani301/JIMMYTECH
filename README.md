# Jimmy Tech Dashboard
App code is in www/index.html. GitHub builds three things from it:
1. Website + installable web app: automatic on every push to main (pages.yml)
2. Windows .exe (installer + portable): release.yml
3. Android APK: release.yml
To build 2 and 3: GitHub > Releases > Draft a new release > new tag v1.0.0 > Publish release.
